导入服务资料

资料隐私与使用声明

文件留在你的设备：你选择的 Excel / CSV 由本机浏览器读取和核对，工具不会将文件内容、名册、服务记录或复核备注上传至网站服务器或 GitHub，也不会自动保存到浏览器的持久存储。

刷新或关闭后需重新导入：本次资料仅供当前页面临时处理。请及时导出需要保留的结果；原始文件不会被工具修改或删除。主动导出的结果会下载到你的设备，请自行妥善保管。

导入前请先脱敏：请另存副本，删除身份证、电话、详细地址、监护人联系方式等不必要的列；记录及备注内的敏感内容也请先删除或遮蔽。工具不会自动脱敏。请按所在机构要求及获授权的范围处理资料。

核对结果仅供初筛：结果受导出资料完整性、日期识别及所选规则影响，可能有遗漏或误判，不作为正式考核结论。请结合原始记录、实际服务、转级时间及适用证明人工复核后使用。

文件只在本机浏览器处理，不上传、不自动保存。自动识别表头、评级历史、服务跟进及服务过程记录；无法自动识别时可手动选择字段。每次导入替换当前名册；多个文件中的人员分开保留，避免同名误合并。

02

设置检查期间

按当时生效的评级，核对联系与见面进度

核对规则与统计口径（可调整）

三级每月跟进、每季度至少见面一次；四级每季度跟进、每年至少一次见面（按你确认的统计口径）；五 / 六级每半年联系。电话可满足联系，不能算见面。只有实际有效服务才应计入，系统简表无法证明是否接通。

勾选的方式计为见面。个案默认不勾选：需确认是否面对面；社区服务按此前口径默认计为见面，可取消。活动 / 小组属于实际参加才计入。评级日期不当服务日期；更新时间不当服务日期。同日同方式合并只用于覆盖核对，不代表系统服务人次。

季度按自然季度（1—3 / 4—6 / 7—9 / 10—12月），不完整季度列待核实。截止日当天视为完整观察日；截止日尚未结束的月份 / 季度只提示进度。半年检查同时参考窗口记录及最近联系间隔；窗口不足半年时不凭零记录判超期。年度要求未到年末列待核实。

无初始评级不倒推，无入册日不假定为评级日。拒绝入户只用于人工复核，不自动豁免月度联系。工具不会把证明备注直接当作服务。
