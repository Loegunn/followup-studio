# 跟进核对台

Excel / CSV 服务跟进记录本机核对工具。无需后端，无需安装依赖。

## 使用

保留同一目录的 index.html、core.js、ui.css、xlsx.min.js。打开 index.html 即可使用，也可放在 GitHub Pages。

导入前请另存副本，删除身份证号、电话、详细地址等不需要的列，以及记录文字中的敏感内容。文件仅在浏览器内读取，不向服务器上传，不自动保存；刷新或关闭页面会丢失本次资料与备注。

必要字段：姓名、带生效日期的服务评级，以及服务跟进或服务过程记录至少一列。仅有服务成效汇总不足以核对具体月份。

资料缺少、日期无法识别或文件读取失败时弹出检查报告；取消导入保留原名册。资料不足人员列待核实，不直接判为记录缺口。可重新打开资料检查报告。

检查开始日默认 2026-05-01，截止日默认 2026-09-30；每次使用请按实际期间调整。

## GitHub Pages

将本目录文件放入仓库根目录。仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支及 / (root)，保存。网站是否成功上线，以 GitHub 显示的发布状态与网址为准。

只提交工具程式，勿提交真实服务对象导出表、检查结果或个人资料。网页访问者各自在本机选择文件，互不共享。

## 范围

三级月度跟进及季度见面、四级季度跟进及年度见面、五六级半年联系。规则与见面方式可在界面调整；一二级提示人工核查。转级、入册时间、拒绝服务证明及未汇入记录仍需人工核实。

本工具用于记录初筛，不代表全部正确或正式考核结论。
